# Bloxorz Solver

## Tổng quan
Dự án giải bài toán Bloxorz sử dụng các thuật toán tìm kiếm: BFS, DFS, UCS, A*.

## Cấu trúc dự án
```
Bloxorz-Solver/
├── Source/
│   ├── main.py                 # Điểm vào, mở GUI
│   ├── README.md               # Hướng dẫn chạy
│   ├── requirements.txt        # Dependencies
│   ├── game/                   # Game logic
│   ├── solvers/                # Các thuật toán tìm kiếm
│   ├── gui/                    # Giao diện đồ họa
│   ├── stages/                 # Dữ liệu các level
│   ├── experiments/            # Benchmark & biểu đồ
│   └── tests/                  # Unit tests
├── report/                     # Báo cáo
├── .gitignore
└── README.md
```
